# MedVentures Hackathon 2026

Инструкции по сдаче проектов хакатона.

## Как устроены репозитории

У каждой команды будет **отдельный приватный репозиторий** в аккаунте `Medventures` с названием от `Haqaton-001` до `Haqaton-040`. Первые 30 репозиториев предназначены для команд, остальные 10 оставлены в резерве. Исходный код размещается в репозитории команды, а не здесь.

Доступ получают только приглашённые GitHub-аккаунты. Организаторы отправляют приглашение на email, привязанный к GitHub, или на GitHub-логин. Ссылка сама по себе не даёт доступ к приватному репозиторию.

## Для участников

1. Примите приглашение GitHub и откройте ссылку на репозиторий своей команды.
2. Загрузите исходный код в `main` своего репозитория. Для совместной работы можно использовать ветки и pull request.
3. Заполните `README.md` по [шаблону команды](TEAM_README_TEMPLATE.md): проблема, решение, состав, запуск и демо.
4. Перед сдачей проверьте, что код и инструкция запуска доступны организаторам.

Не добавляйте пароли, токены, файлы `.env`, персональные данные и большие сгенерированные файлы. Храните нужные настройки в `.env.example` без секретных значений.

## Для организаторов

Для каждой команды создайте отдельный приватный репозиторий из [шаблона команды](https://github.com/Medventures/hack-team-template) и добавьте участников этой команды. После хакатона репозитории можно архивировать. Публичность можно изменить отдельно, когда будет принято решение о публикации работ.
