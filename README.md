# MedVentures Hackathon 2026

Список репозиториев команд и инструкции по сдаче проектов хакатона.

## Как устроены репозитории

Для команд созданы **50 отдельных публичных репозиториев** в аккаунте `Medventures` с названиями от [`Haqaton-001`](https://github.com/Medventures/Haqaton-001) до [`Haqaton-050`](https://github.com/Medventures/Haqaton-050). Первые 30 репозиториев предназначены для команд, остальные 20 оставлены в резерве. Исходный код размещается в репозитории команды, а не здесь.

Просматривать публичные репозитории может любой человек по ссылке. Любой участник хакатона может [запросить доступ коллаборатора](https://github.com/Medventures/medventures-hackathon-2026/issues/new?template=collaborator-request.yml) к любому из 50 командных репозиториев: укажите свой GitHub-логин, команду и нужные номера репозиториев. После проверки участия организатор отправит приглашение; для прямой загрузки кода его нужно принять в GitHub. Сама ссылка на публичный репозиторий права записи не даёт. Без приглашения можно предложить изменения через fork и pull request.

## Для участников

1. Получите номер репозитория своей команды от организаторов и откройте его ссылку. Чтобы стать коллаборатором в нём или в другом командном репозитории, [отправьте запрос](https://github.com/Medventures/medventures-hackathon-2026/issues/new?template=collaborator-request.yml) и примите приглашение GitHub.
2. Загрузите исходный код в `main` нужного репозитория после получения доступа. Для совместной работы можно использовать ветки и pull request.
3. Заполните `README.md` по [шаблону команды](TEAM_README_TEMPLATE.md): проблема, решение, состав, запуск и демо.
4. Перед сдачей проверьте, что код и инструкция запуска доступны организаторам.

Не добавляйте пароли, токены, файлы `.env`, персональные данные и большие сгенерированные файлы. Храните нужные настройки в `.env.example` без секретных значений.

## Для организаторов

Назначьте каждой команде один из уже созданных репозиториев. Проверяйте [запросы на доступ](https://github.com/Medventures/medventures-hackathon-2026/issues?q=is%3Aissue) и приглашайте участников в выбранные ими командные репозитории. Для описания проекта используйте [шаблон README](TEAM_README_TEMPLATE.md). После хакатона репозитории можно архивировать.
